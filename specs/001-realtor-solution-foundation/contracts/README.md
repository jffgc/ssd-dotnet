# Contratos de la foundation

La iniciativa foundation no expone contratos funcionales ni endpoints de negocio. En esta fase, el objetivo es preparara la solución para ser extendida por futuras features, pero sin definir interfaces comerciales ni APIs de dominio.

## Estado actual

- No se publican endpoints de negocio.
- No existen contratos de request/response para dominio.
- No se definen DTOs ni esquemas de integración en esta iniciativa.

## Política

Cualquier contrato externo y cualquier endpoint funcional se documentará en la iniciativa correspondiente cuando la estructura funcional y la API estén formalizadas.
